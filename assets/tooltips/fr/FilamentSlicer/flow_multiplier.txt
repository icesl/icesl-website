Multiplicateur de flux
Multiplicateur de flux pour cette brush.
Augmenter ou réduire pour extruder artificiellement
plus ou moins de matière.
Pour éviter de dépasser la valeur maximale d'extrusion,
la vitesse d'impression est réduite lorsque le
multiplicateur de flux est supérieur à 1.
Pour le remplissage, le multiplicateur peut changer
pour s'adapter aux espaces étroits.
Pour les ponts, le flux est augmenté de 20%.
Ce multiplicateur n'affecte pas les éléments
suivants:
	- la tour
	- le brim
	- le bouclier
Attention, le paramètre
'Multiplicateur de vitesse selon le flux' a également
un impact sur la viesse d'impression.
