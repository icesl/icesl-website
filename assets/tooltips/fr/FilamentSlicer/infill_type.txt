Type de remplissage
Type de remplissage pour un brush donné. 
IceSL propose quatre options décrites ci-dessous.
Il est possible d'ajouter un remplissage personnalisé
en écrivant sa spécification (voir fichier 'README.md'
dans le dossier 'icesl-infillers'):

-Default(Défaut): Remplissage tétrahédral (meilleure solution
dans la majorité des situations).

-Progressive(Progressif): Les variations dans le pourcentage 
de remplissage produisent une variation lisse 
dans le résultat.

-Cubic(Cubique): Remplissage cubique sans variation progressive.

-Polyfoam: Structure sembable à une éponge. 
Voir les paramètres ci-dessous pour plus de 
contrôle sur le résultat.

-Phasor: Remplissage utilisant un bruit procédural
de phasor; structure très flexible. Voir les
paramètres ci-dessous pour plus de contrôle sur le
résultat.
