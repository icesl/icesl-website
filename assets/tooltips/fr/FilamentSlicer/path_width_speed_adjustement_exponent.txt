Changement de vitesse
Exposant de changement de vitesse pour les 
changements d'épaisseur. Si le remplissage avec 
un seul chemin est actif, IceSL pourra génerer 
un chemin plus large que le diamètre de sortie 
de la buse. En fonction du matériau, il peut être 
nécessaire de ralentir la vitesse d'impression.
Cet exposant control le ralentissement. Par exemple:
0.0 => pas de ralentissement
1.0 => linéaire, vitesse d'extrusion constante
2.0 => quatre fois plus lent pour deux fois la largeur
3.0 => huit fois plus lent pour deux fois la largeur
Nous recommendons 3.0 comme valeur fiable.
