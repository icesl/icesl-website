Método de tiempo mínimo
- Tower: Genera una torre para garantizar el tiempo mínimo
de impresión de cada capa.

- Shield: Genera un escudo para garantizar el tiempo mínimo
de impresión de cada capa.

- Function 'wait': Permite al usuario especificar el compor-
tamiento de la impresora para garantizar el tiempo mínimo
de impresión de cada capa. Ver la documentación de perfiles
de impresora.
