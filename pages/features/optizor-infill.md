The Optizor infiller allows the user to recreate, through light reflection, any image as a printed flat surface. 

[![][optizor-infill]{:.img-small}][optizor-infill]

{:.caption1}
<sup>Recreation of the [Kanagawa Wave][kanagawa-wave] through IceSL's optizor infiller </sup>

Publications:
 - [Orientable Dense Cyclic Infill for Anisotropic Appearance Fabrication][optizor-paper]
 - Xavier Chermain, Cédric Zanni, Jonàs Martínez, Pierre-Alexandre Hugron, Sylvain Lefebvre
 - ACM Transactions on Graphics
