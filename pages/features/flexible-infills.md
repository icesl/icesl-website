IceSL allows printing objects with deformation properties via the Polyfoam and Phasor infillers. The user can control locally the density, infill orientation, direction and randomness to obtain a desired deformation. 

[![][flexible-infills]{:.img-small}][flexible-infills]

{:.caption1}
<sup>Cube printed using the Phasor infiller. A deformation property was given with specific infill parameters.</sup>

Publications:

 - Jonàs Martínez, Samuel Hornus, Haichuan Song, Sylvain Lefebvre
 - ACM Transactions on Graphics 2018
